# Pixal3D Pinokio Launcher

Pixal3D generates high-fidelity 3D assets from a single input image. This launcher installs the TencentARC/Pixal3D Gradio app and starts a local web UI in Pinokio.

This repository contains the Pinokio launcher and compatibility wrapper only. The Pixal3D application source is cloned from `TencentARC/Pixal3D` during installation, and model weights are downloaded from their upstream Hugging Face repositories at runtime.

## Requirements

Local mode requires Linux with an NVIDIA CUDA GPU. On Windows, this launcher runs Pixal3D inside WSL Ubuntu so the Linux CUDA wheels can be used.

The upstream TRELLIS.2 base and Pixal3D demo depend on Linux CUDA wheels for `o_voxel`, `cumesh`, `flex_gemm`, `nvdiffrast`, `nvdiffrec_render`, `natten`, and `flash_attn_3`.

The WSL installer creates a private environment under `~/.pinokio-pixal3d` inside Ubuntu.

Pixal3D also downloads `briaai/RMBG-2.0` for background removal. That model is gated on Hugging Face, so accept access at <https://huggingface.co/briaai/RMBG-2.0> and provide a read token from <https://huggingface.co/settings/tokens> when Pinokio asks for `HF_TOKEN`.

RTX 50-series GPUs may print a PyTorch CUDA capability warning because the upstream Pixal3D wheel set currently pins Torch 2.6/CUDA 12.4. The launcher still opens the web UI, but generation depends on upstream wheel support for your GPU.

On RTX 50-series / Blackwell GPUs, click Install or Update after installing WSL support. The WSL installer detects compute capability 12.x and replaces the upstream Torch 2.6/CUDA 12.4 stack with a CUDA 12.8 Torch stack and matching Pixal3D wheels.

On RTX 50-series / Blackwell GPUs in WSL, this launcher uses Low VRAM mode even if Standard mode is requested. Standard mode currently leaves the CUDA context in a `device not ready` state during Pixal3D's high-resolution conditioning stage.

## Usage

1. Click Install in WSL on Windows, or Install on Linux.
2. If prompted, enter `HF_TOKEN` after accepting access to `briaai/RMBG-2.0`.
3. Click Start WSL Low VRAM. Standard mode is only shown on non-Blackwell setups.
4. Open the Web UI when Pinokio shows it.
5. Upload an image, generate previews, then extract the GLB.

The first generation may take a while because Hugging Face model weights are downloaded and cached.

## API

Pixal3D exposes a Gradio API from the launched base URL.

Replace `http://127.0.0.1:7860` in the examples below with the URL Pinokio shows after launch.

### JavaScript

```js
import { Client, handle_file } from "@gradio/client";

const client = await Client.connect("http://127.0.0.1:7860");
const preprocessed = await client.predict("/preprocess", {
  image: handle_file("./input.png")
});

const generated = await client.predict("/generate_3d", {
  image: preprocessed.data[0],
  seed: 42,
  resolution: 1024,
  ss_guidance_strength: 7.5,
  ss_guidance_rescale: 0.7,
  ss_sampling_steps: 12,
  ss_rescale_t: 5.0,
  shape_slat_guidance_strength: 7.5,
  shape_slat_guidance_rescale: 0.5,
  shape_slat_sampling_steps: 12,
  shape_slat_rescale_t: 3.0,
  tex_slat_guidance_strength: 1.0,
  tex_slat_guidance_rescale: 0.0,
  tex_slat_sampling_steps: 12,
  tex_slat_rescale_t: 3.0,
  manual_fov: -1,
  fov_unit: "deg",
  session_id: crypto.randomUUID()
});

const glb = await client.predict("/extract_glb_api", {
  state_path: generated.data[0].state_path,
  decimation_target: 1000000,
  texture_size: 4096,
  session_id: crypto.randomUUID()
});
```

### Python

```python
from gradio_client import Client, handle_file
from uuid import uuid4

client = Client("http://127.0.0.1:7860")
preprocessed = client.predict(image=handle_file("input.png"), api_name="/preprocess")
generated = client.predict(
    image=preprocessed,
    seed=42,
    resolution=1024,
    ss_guidance_strength=7.5,
    ss_guidance_rescale=0.7,
    ss_sampling_steps=12,
    ss_rescale_t=5.0,
    shape_slat_guidance_strength=7.5,
    shape_slat_guidance_rescale=0.5,
    shape_slat_sampling_steps=12,
    shape_slat_rescale_t=3.0,
    tex_slat_guidance_strength=1.0,
    tex_slat_guidance_rescale=0.0,
    tex_slat_sampling_steps=12,
    tex_slat_rescale_t=3.0,
    manual_fov=-1,
    fov_unit="deg",
    session_id=str(uuid4()),
    api_name="/generate_3d",
)
glb = client.predict(
    state_path=generated["state_path"],
    decimation_target=1000000,
    texture_size=4096,
    session_id=str(uuid4()),
    api_name="/extract_glb_api",
)
```

### Curl

The simple status/config endpoints can be called directly:

```bash
curl http://127.0.0.1:7860/app_config
curl "http://127.0.0.1:7860/progress?session_id=<session-id>"
```

For image upload and generation, Gradio's REST payload includes uploaded file metadata. Open `http://127.0.0.1:7860/?view=api` after launch to copy the exact curl examples generated by the installed Gradio version.
